# Googleビジネスプロフィール 登録手順書（翔葵丸）

船長向けの手順書です。ITが苦手でも進められるよう、順番どおりに進めればOKです。

## 1. なぜやるか

「萩 釣り船」「萩 イカ釣り」などで検索したときに、Googleマップの枠（地図＋お店一覧）に翔葵丸を表示させるためです。
無料で登録でき、萩市内やその周辺でお客様を探している人に一番届きやすい施策です。
公式サイト（shokimaru.com）や口コミと連携して表示されるので、集客の入り口として最優先で整えましょう。

## 2. 登録手順

1. https://business.google.com にアクセスし、お店用に使うGoogleアカウントでログイン
   （個人のGmailで問題ありません。今後もこのアカウントで管理します）
2. 「ビジネスを管理」→ ビジネス名に **「翔葵丸」** と入力
3. カテゴリを選択：**「釣りチャーター」（Fishing charter）** を推奨
   （候補になければ「遊漁船」「釣り船」等、近い日本語カテゴリでも可）
4. 拠点の登録方法を選ぶ
   - お客様が実際に船に乗るために訪れる場所（玉江漁港）を **店舗所在地** として登録するのが基本
   - もし港に看板や常設の受付がなく「予約制で港に集合するだけ」の運用が実態に近い場合は、
     住所を非公開にして **「サービス提供エリア」型** を選ぶ選択肢もあります
     （迷ったら店舗所在地タイプでOKです）
   - 住所：（船長が入力／玉江漁港の住所）
5. 電話番号を入力：（船長が入力）
6. ウェブサイトを入力：`https://shokimaru.com`
7. 登録内容を確認して次へ進む
8. オーナー確認を行う
   - 画面の案内に従い、**ハガキ・電話・動画確認** などGoogleが提示する方法で本人確認を行う
   - ハガキの場合、届くまで1〜2週間かかることがあるので早めに申請する
   - 確認が完了するまでは検索結果に表示されないので、届いたらすぐにコードを入力する

## 3. 登録後にやること

### 営業時間
- 出船スケジュールに合わせて「営業時間」を設定する
- 早朝出船・夜釣り（ナイトティップラン）がある場合は、実際の受付時間帯（予約・電話対応が可能な時間）を目安に設定するとお客様に伝わりやすい
- 定休日がなく不定期出船の場合は「特別営業時間」欄で個別に調整も可能

### 写真
- 船の外観・内観、釣果（イカ・SLJの魚）、玉江漁港の様子など **10枚以上** アップロード
- 明るく、魚やイカが大きく写っている写真を優先

### サービス・料金
- 「乗り合い」「チャーター」「レンタルタックル」をサービスとして登録し、それぞれの料金を記載
  （例：乗り合い9,000円／人、チャーター60,000円／隻、レンタル1,000円／セット）

### 説明文（例文）
以下をそのまま、または一部調整して使えます（150字程度）。

> 山口県萩市・玉江漁港発の釣り船「翔葵丸」です。萩湾でのナイトティップラン・イカメタルによるイカ釣りを中心に、SLJも楽しめます。初心者・女性も大歓迎で、道具のレンタルもあり手ぶらでOK。最大8名まで乗船可能、乗り合い・チャーターどちらも承ります。

## 4. 運用のコツ

- **最新情報への投稿**：釣果写真を月に数回、「最新情報」機能から投稿する（そのまま検索結果にも表示されやすくなる）
- **口コミのお願い**：乗船後、お客様に一声かける
  > 「よろしければ、Googleのクチコミに今日の釣行の感想を書いていただけると嬉しいです！」
  スマホでその場にGoogleの口コミページ（QRコードでもOK）を見せると書いてもらいやすい
- **口コミへの返信**：良い評価・悪い評価にかかわらず、必ず返信する（お礼や次回のご案内でOK。放置しない）

## 5. 注意点

- サイト（shokimaru.com）・GBP・SNS・その他掲載媒体で、**店名・住所・電話番号の表記を完全に揃える**（NAP一貫性）
  - 例：「翔葵丸」の表記ゆれ（（しょうきまる）の有無など）や、電話番号のハイフンの有無を統一する
- 表記がバラバラだとGoogleに「同じお店」と正しく認識されず、検索順位が下がる原因になるので要注意
